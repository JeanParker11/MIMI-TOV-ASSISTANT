---
## 1. HÉMORRAGIE
---

L'Hémorragie est un état grave qui sanctionne un combattant ayant subi des blessures profondes répétées.

* *Déclencheur* : L'état s'active automatiquement dès qu'un combattant accumule son troisième effet "Saignement". À cet instant, les cumuls de Saignement sont consommés pour laisser place à l'Hémorragie.

* *Effet* : Tant qu'un combattant est victime d'Hémorragie, il perd 10% de ses points de vie *actuels* au tout début de chacune de ses actions (que ce soit une attaque, une défense, ou une autre compétence). Les dégâts sont calculés avant que l'action ne soit résolue.

* *Durée* : L'Hémorragie est un état permanent qui dure jusqu'à la fin du combat. Il ne peut être ni soigné ni purgé par des moyens standards.

---
## 2. GESTION DE L'INACTIVITÉ
---

Ce système est conçu pour maintenir le rythme du combat tout en offrant une certaine flexibilité pour pallier les problèmes de connexion ou les hésitations. Il repose sur un minuteur de 10 minutes par tour, des jetons de pénalité et une unique période de grâce.

* *Le Minuteur de Tour (10 minutes)* :
    * À chaque début de tour, un décompte de 10 minutes est lancé pour le joueur actif.
    * Des rappels automatiques sont envoyés à des moments clés pour informer le joueur du temps restant : à 5 minutes, 2 minutes, et 1 minute de la fin.

* *L'État d'Immobilité* :
    * Si le joueur n'envoie pas son action avant la fin des 10 minutes, il est considéré comme "immobile".
    * L'immobilité a pour effet d'annuler toute action ou sort qui était en préparation et qui devait se poursuivre durant ce tour. Le joueur devient alors vulnérable.

* *La Période de Grâce (1 minute)* :
    * Dès qu'un joueur devient immobile, une "période de grâce" d'une minute est déclenchée.
    * Le joueur en retard a la possibilité d'envoyer son action pendant cette minute supplémentaire.
    * *Important* : Chaque joueur ne peut bénéficier de cette grâce *qu'une seule fois* par combat.

* *Les Jetons d'Inactivité et le Forfait* :
    * Si un joueur utilise sa période de grâce avec succès, aucune pénalité n'est appliquée, mais sa "grâce" est consommée pour le reste du duel.
    * S'il n'envoie toujours pas son action à la fin de la minute de grâce (ou s'il avait déjà utilisé sa grâce), il reçoit *1 jeton d'inactivité*.
    * Son tour est alors sauté, et son adversaire peut jouer à nouveau.
    * L'accumulation de *3 jetons d'inactivité* au cours du combat entraîne un *forfait* immédiat.

// On importe le module 'fs' (File System) pour lire les fichiers
const fs = require('fs');

/**
 * Lit et analyse le fichier Arènes.txt pour en extraire une liste structurée d'arènes.
 * @returns {Array<Object>} Un tableau d'objets, chaque objet représentant une arène.
 */
function parseArenasFile() {
    // 1. Lire le contenu brut du fichier texte
    const fileContent = fs.readFileSync('./data/Arènes.txt', 'utf8');

    // 2. Séparer le fichier en blocs, un pour chaque arène.
    // On utilise la ligne de séparation comme délimiteur.
    const arenaBlocks = fileContent.split(/▔▔▔▔▔▔▔▔▔▔/g);

    const arenas = [];

    // 3. Boucler sur chaque bloc de texte pour l'analyser
    for (const block of arenaBlocks) {
        if (block.trim().length === 0) continue; // Ignorer les blocs vides

        const arenaObject = {};

        // 4. Extraire le nom de l'arène (la première ligne non vide)
        const lines = block.trim().split('\n');
        arenaObject.nom = lines[0].trim();

        // 5. Extraire les propriétés et aléas avec des expressions régulières (regex)
        // Regex pour trouver une ligne commençant par "➠"
        const propRegex = /➠\s*(.+?)\s*:\s*(.+)/;

        arenaObject.proprietes = {};
        arenaObject.aleas = [];

        for (const line of lines) {
            const match = line.match(propRegex);
            if (match) {
                const key = match[1].toLowerCase().trim(); // ex: "périmètre"
                const value = match[2].trim(); // ex: "125 m (20 m de rayon)"

                // Logique pour trier les propriétés et les aléas
                if (key.includes('poteaux')) {
                    arenaObject.aleas.push({
                        type: 'projection_obstacle',
                        nom_obstacle: 'Poteau de bois',
                        [span_0](start_span)resistance_obstacle: 10 // Extrait de "10 Rs"[span_0](end_span)
                    });
                } else if (key.includes('hypothermie')) {
                     arenaObject.aleas.push({
                        type: 'environnement_mortel',
                        [span_1](start_span)[span_2](start_span)declencheur: { condition: 'fin_du_tour', valeur: 4 }, //[span_1](end_span)[span_2](end_span)
                        description: "L'hypothermie entraîne la mort après 4 tours." [span_3](start_span)[span_4](start_span)//[span_3](end_span)[span_4](end_span)
                    });
                }
                else {
                    // C'est une propriété standard
                    arenaObject.proprietes[key] = value;
                }
            }
        }
        
        // Ajouter l'objet arène structuré à notre tableau final
        arenas.push(arenaObject);
    }

    return arenas;
}

 * Séparation en Blocs : Il utilise la ligne ▔▔▔▔▔▔▔▔▔▔ comme un séparateur pour découper le fichier en plusieurs morceaux, où chaque morceau est une arène.
 * Extraction du Nom : Pour chaque morceau, il considère que la première ligne est le nom de l'arène.

// On ajoute cette fonction dans le même fichier que le parser

/**
 * Nettoie une chaîne de caractères pour faciliter la comparaison.
 * @param {string} text Le texte à nettoyer.
 * @returns {string} Le texte nettoyé.
 */
function nettoyerTexte(text) {
    if (!text) return '';
    return text
        .toLowerCase()
        // Expression régulière pour enlever la plupart des symboles et emojis
        .replace(/([\u2700-\u27BF]|[\uE000-\uF8FF]|\uD83C[\uDC00-\uDFFF]|\uD83D[\uDC00-\uDFFF]|[\u2011-\u26FF]|\uD83E[\uDD10-\uDDFF])/g, '')
        .replace(/[^\w\sàâçéèêëîïôûùüÿ]/gi, '') // Garde les caractères alphanumériques et accentués
        .trim();
}

/**
 * Trouve une arène correspondant aux informations d'un groupe WhatsApp.
 * @param {object} groupInfo - Objet contenant { nom, description }.
 * @returns {object|null} L'objet de l'arène trouvée ou null.
 */
function findArenaByGroupInfo(groupInfo) {
    // 1. Obtenir toutes les arènes structurées
    const allArenas = parseArenasFile();
    
    // 2. Nettoyer les infos du groupe une seule fois
    const groupNameClean = nettoyerTexte(groupInfo.nom);
    const groupDescClean = nettoyerTexte(groupInfo.description);
    const groupTextToSearch = groupNameClean + ' ' + groupDescClean;

    // 3. Chercher une correspondance
    for (const arena of allArenas) {
        const arenaNameClean = nettoyerTexte(arena.nom);
        
        // Si le nom ou la description du groupe contient le nom de l'arène
        if (groupTextToSearch.includes(arenaNameClean)) {
            // 4. On a trouvé ! On retourne l'objet complet de l'arène.
            return arena;
        }
    }
    
    // 5. Aucune correspondance trouvée
    return null;
}

module.exports = { parseArenasFile, findArenaByGroupInfo };

// lib/combatLogic.js

/**
 * Résout l'impact d'une action.
 * @param {object} combatState - L'état complet du combat (incluant l'arène).
 * @param {object} attaquant - Le joueur qui attaque.
 * @param {object} defenseur - Le joueur qui défend.
 * @param {object} action - L'action effectuée (ex: { nom: "Coup de pied sauté", tags: ["projection"] }).
 */
function resoudreImpact(combatState, attaquant, defenseur, action) {
    // ... calculs des dégâts de base, esquive, etc. ...

    // --- LOGIQUE D'ALÉA D'ARÈNE ---
    // On vérifie si l'arène existe et si l'action peut déclencher un aléa.
    if (combatState.arene && action.tags.includes('projection')) {
        
        // On cherche un aléa de type "projection_obstacle" dans l'arène actuelle
        const aleaObstacle = combatState.arene.aleas.find(a => a.type === 'projection_obstacle');
        
        if (aleaObstacle) {
            const degatsSupplementaires = aleaObstacle.resistance_obstacle || 10;
            defenseur.pv -= degatsSupplementaires;
            
            // On ajoute un message spécifique au log du combat
            combatState.log.push(
                `${attaquant.nom} projette ${defenseur.nom} contre un ${aleaObstacle.nom_obstacle} ! ` +
                Il subit ${degatsSupplementaires} dégâts supplémentaires.
            );
        }
    }
    // --- FIN DE LA LOGIQUE D'ALÉA ---

    return combatState;
}
